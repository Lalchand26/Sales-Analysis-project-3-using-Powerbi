Sales Performance Dashboard 
This project is a data visualization dashboard designed to track and analyze sales performance across different Indian states and product segments. 
Dashboard Features 
1. Key Performance Indicators (KPIs) • Average Order Value (AOV): A central scorecard displays the current average order value, which is currently 1.60K. 

2. Geographical Sales Analysis • Sales by State: A bar chart comparing total sales across various states including Gujarat, Delhi, West Bengal, Maharashtra, and others. 
• State Rank and Total Orders: A horizontal bar chart visualizing the ranking and volume of orders per state. 

3. Segment & Category Breakdown • Average Order Value by Segment: A pie chart illustrating the distribution of order values between different segments: 

	• Corporate: Representing 60% (1.8K) 
	• Consumer: Representing 40% (1.2K) 

• Sub-Category Filter: An interactive selector to filter data by product types such as: 

	• Accessories, Audio, Chairs, Computers (currently selected), Mobiles, Printers, Storage, and Tables.
